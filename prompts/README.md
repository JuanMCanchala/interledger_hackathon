What was built with AI and how it was verified is summarized in [`AI_USAGE.md`](../AI_USAGE.md).

| Person               | Tools and models                                                        | Log                                                        |

- Juan's log was exported from his Claude Code session; Brayan's and Isabella's are published as
  they exported them. Juan's and Isabella's keep the exact text of every prompt, typos included.
- Secrets that were pasted into a prompt (a private key, an API token, an admin URL) are replaced
  with `[REDACTADO: …]`; the text of the prompts is otherwise unchanged.
- The prompts are in Spanish, the language the team worked in.
